# Agency Portfolio Website — Codex Build Prompt

## Project goal
Build a polished **3-page React/Vite agency website** for a fictional digital marketing / creative agency.

This project is for a web design portfolio and should look like the type of professional €160 business website that could be sold to small businesses.

The website should demonstrate:
- multi-page React routing
- responsive layouts
- reusable components
- good typography
- forms
- subtle animations
- SEO metadata
- clean navigation
- mobile menu
- polished UI
- deployment-ready frontend quality

Do **not** add complicated backend features. This is a professional frontend showcase, not a SaaS.

---

## Suggested fictional agency
Use a fictional agency name such as:

**NovaHaus Studio**

Positioning:

> We help ambitious brands grow with better design and digital strategy.

The agency should feel like a modern digital marketing / creative studio that offers web design, branding, and digital marketing.

---

## Tech stack
Use:
- React
- TypeScript
- Vite
- React Router
- CSS modules, normal CSS
- Optional: Framer Motion for subtle animations
- Optional: Lucide React for icons

Keep the app frontend-only.

---

## Pages
Create exactly 3 main pages:

1. **Home**
2. **Services**
3. **About / Contact**

Use a shared layout with:
- Navbar
- Main page content
- Footer

## Design direction
Do not make this look like a generic beginner website.

Use:
- lots of whitespace
- large typography
- one strong accent color
- subtle gradients
- rounded cards
- good spacing
- strong imagery / mockup visuals
- subtle animations
- consistent button styles
- responsive mobile navigation

Recommended visual direction:
- black / off-white background
- electric blue or purple accent
- clean gradient glow effects
- modern agency-style cards

Color direction example:
- Background: #070A12 or #0B0D12
- Surface cards: #111827 or #121826
- Text: #F8FAFC
- Muted text: #94A3B8
- Accent: #6366F1, #7C3AED, or #38BDF8
- Border: rgba(255,255,255,0.08)

Typography:
- Heading: Manrope, Sora, or Plus Jakarta Sans
- Body: Inter

The site must work well on:

- tablet
- mobile

## Animation guidance
Use subtle animations only:
- fade in sections
- cards lift slightly on hover
- buttons have smooth hover states
- hero visual can have gentle floating elements

Do not overdo animations.

2. who it helps

The homepage should be the strongest page and should work as a portfolio showcase.
